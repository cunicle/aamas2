# Use of AI-assisted technologies

We used Claude Opus 5.5 (Anthropic) through Claude Code throughout this project: in interactive sessions with the authors, in sub-agents those sessions started, and in separate sessions that ran the experiments on rented GPUs. The AI wrote the code (the library, the run and analysis scripts, and the unit tests), computed every statistic, table and figure by script from the raw records, drafted and revised the text, and proposed experiments B, C and D (teams of agents on choose-N and on BFCL, the closing token in the slot, one slot longer, format-tolerant slots, and position agents) in response to the authors' questions and to mock reviews. Sub-agents checked every reference against its source, audited every number in the text against the raw records, and wrote mock reviews whose findings led to corrections.

The authors set the research question, the venue and the rules for the work: numbers that were not run are marked as such, results that contradict a prediction are reported as they are, and every reference is checked against its source. They decided which of the proposed experiments to run and chose the paper's structure and title from the AI's proposals. Each approved experiment was specified in advance, with its predictions and with checks that stop a run on unexpected behaviour, and run by a separate session that reported back. The prompts given to the models in the experiments are in `PROMPTS.md`.
